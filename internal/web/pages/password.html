Power on

A shell command that switches the cluster's machine on, through its BMC (iLO, iDRAC, IPMI), Wake-on-LAN or anything else. While the cluster is offline its pages offer Start server, which runs it here for a minute at most, with the user and the password as $SY_POWER_USER and $SY_POWER_PASSWORD. An empty command removes it.

It runs on this machine as switchyard's user: hence the password.
The login is off: whoever reaches switchyard can use it.
